KOUT KOUT — LETTER + PHOTOS ONLY 💗

1. Open index.html in a browser to preview it.
2. The photo picker is a local preview only. For photos to appear for Kout Kout on the published site:
   - Create a folder called photos beside index.html.
   - Copy your photos into it, e.g. photo1.jpg, photo2.jpg, photo3.jpg.
   - In index.html, replace each photo placeholder with an image element like:
     <img src="photos/photo1.jpg" alt="Our favorite photo together">
     Repeat with photo2.jpg and photo3.jpg. Keep each photo file in the photos folder.
3. Edit the love letter in index.html to add personal memories or your own words.
4. Publish for free using GitHub Pages:
   - Sign in at https://github.com and create a repository such as kout-kout-birthday.
   - Upload index.html and the photos folder.
   - Go to Settings > Pages.
   - Choose Deploy from a branch, select main and /(root), and Save.
   - Once published, your link will look like https://YOUR-USERNAME.github.io/kout-kout-birthday/
5. Test the link on your phone before sending it.

Privacy: a public GitHub Pages site can be viewed by anyone who has or finds the URL. Only upload photos you are comfortable sharing online.
